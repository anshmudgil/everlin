# Full IC-Brief Data Sources — Primary-Source Research

**Purpose:** Extend Everlin's free/no-key/ToS-safe retrieval layer (already covering RBA cash rate F1, ABS CPI+GDP, US Treasury fiscaldata) to the remaining macro/market figures in the golden IC brief, at the same bar: *no ToS landmine, no scraping, commercially usable in a client-facing consulting product.*

**Method:** Every endpoint below was fetched live (HTTP status + payload shape confirmed) or its licensing page read directly. Verification date: **2026-09-10**. Verdicts are for a **commercial, customer-facing** product — stricter than personal/internal use.

**Headline reality:** The *macro/official-statistics* layer (FX, commodities, government economic series) is genuinely ship-safe and free. The *market-index and single-security* layer (ASX 200, S&P 500, Dow, VIX, etc.) is **licensed intellectual property** — S&P DJI, CBOE, ASX, and the exchanges each own their index/quote data, and every "free" pipe to it (FRED, Yahoo, WorldMonitor) inherits that restriction. There is no clean free commercial source for headline index *levels*. This is an honest, structural gap, not a search failure.

## 1. FX — AUD/USD + AUD cross rates

### 1a. RBA Table F11.1 — Exchange Rates, Daily (PRIMARY, recommended)

- **Base URL (verified HTTP 200, 137 KB, `application/octet-stream`):**
  `https://www.rba.gov.au/statistics/tables/csv/f11.1-data.csv`
- **Format:** CSV, same header block family as F1 (Title / Description / Frequency / Type / Units / Source / Publication date / Series ID rows, then dated rows). Machine-readable, stable schema.
- **AUD/USD series:** first data column, header `A$1=USD`, **Series ID `FXRUSD`**, quoted as AUD1 = USD (e.g. `09-Sep-2026 → 0.6xxx`). Source noted as **WM/Reuters**.
- **Cross rates in the same file (all `A$1=…`, one column each):** CNY `FXRCR`, JPY `FXRJY`, EUR `FXREUR`, KRW, GBP `FXRUKPS`, SGD, INR, THB, NZD `FXRNZD`, TWD, MYR, IDR, VND, AED, PGK, HKD, CAD `FXRCD`, ZAR, CHF `FXRSF`, PHP, plus the Trade-Weighted Index `FXRTWI` and SDR (IMF-sourced). Covers every cross a typical AU IC brief needs.
- **Auth:** none. **Rate limits:** none published; single daily-updated file.
- **ToS:** RBA material is **CC BY 4.0** (https://www.rba.gov.au/copyright/), commercial use + redistribution allowed with attribution "Source: RBA [year]", no implied endorsement.
- **CAUTION nuance — the FX carve-out is real.** The RBA copyright page's CC BY 4.0 grant explicitly **excludes third-party-sourced material**, and the F11.1 rates are **sourced from WM/Reuters** (SDR from IMF), not generated by the RBA. RBA also disclaims any financial-instrument use that "references or relies on" the data. So the *file* is free to fetch and the *numbers* are fine to state in a brief as "AUD/USD per RBA F11.1", but do **not** market Everlin as redistributing a WM/Reuters FX feed. For "state today's AUD/USD in a consulting brief with attribution," this is **SHIP-SAFE**; for "resell a live FX data product," it is CAUTION.

### 1b. ECB Data Portal (SDMX) — official EU FX reference rates (PRIMARY alternative)

- **Base URL (verified HTTP 200, `text/csv`):**
  `https://data-api.ecb.europa.eu/service/data/EXR/D.USD.EUR.SP00.A?lastNObservations=1&format=csvdata`
  AUD leg: `https://data-api.ecb.europa.eu/service/data/EXR/D.AUD.EUR.SP00.A?...`
- **Confirmed live values:** EUR/USD `2026-09-09 → 1.1652`; AUD/EUR `2026-09-09 → 1.6128`. To get AUD/USD you cross the two EUR legs (ECB publishes vs EUR only). Both legs returned clean SDMX-CSV with full metadata columns.
- **Format:** SDMX (CSV / JSON / XML via `format=` param), fully documented, no key.
- **Auth:** none. **Rate limits:** none published for the public data-API; fair-use.
- **ToS:** ECB permits **free reuse including commercial**, with source acknowledgement ("Source: European Central Bank"). ECB reference rates are the bank's own product (not third-party-relicensed like RBA's WM/Reuters feed), which makes ECB the **cleaner redistribution story** than F11.1 if Everlin ever wants to *republish* an FX series rather than just quote it. **Verdict: SHIP-SAFE.**
- **Caveat:** ECB rates are daily ~14:15 CET reference fixings vs EUR only; AUD/USD is a derived cross, not a directly published pair.

### 1c. Rejected free-FX option — exchangerate.host

- `https://api.exchangerate.host/latest?base=AUD&symbols=USD` now returns **HTTP 200 with `"missing_access_key"` error** — the formerly-free keyless service now **requires an API key** (apilayer commercialization). **No longer a clean free source. Skip.**

**FX verdict:** Use **RBA F11.1** for AUD/USD + all AUD crosses in-brief (it is literally the same CSV family as F1 you already ship), and keep **ECB Data Portal** as the clean-redistribution backup. Both SHIP-SAFE for a consulting brief.

## 2. ASX 200 index level

- **Owner:** The index is **S&P/ASX 200**, jointly the IP of **S&P Dow Jones Indices** and **ASX**. The *level* is licensed data.
- **ASX itself:** does not offer a free, keyless, commercially-redistributable API for the index level; official/real-time index data is a paid market-data licence.
- **FRED:** does **not** carry S&P/ASX 200.
- **Yahoo Finance (`^AXJO`):** technically returns the level, but Yahoo's ToS prohibits redistribution/commercial use of the feed, and there is no supported public API — using it in a paid product is a **ToS + IP landmine** on two counts (Yahoo ToS + S&P/ASX ownership).
- **Trading Economics:** free tier is non-commercial and rate-gated; commercial use requires a paid subscription. Not clean.
- **Govt/RBA proxy:** RBA publishes broad financial-aggregate tables but **not** the S&P/ASX 200 index level. No free official proxy exists for the headline level.
- **Verdict: LANDMINE.** There is no free, official, commercially-usable source for the S&P/ASX 200 *level*. Options: (a) licence it (S&P DJI / ASX / a vendor like Refinitiv), or (b) in the brief, cite the level as "S&P/ASX 200, source: <licensed provider>" and obtain that number under licence — never scrape Yahoo. Same conclusion the project already reached for CBA/BHP/CSL single equities.

## 3. Commodities — Brent oil, gold

### 3a. Brent crude — EIA Open Data (PRIMARY, recommended)

- **Base URL (verified — endpoint resolves, returns `403 API_KEY_MISSING` without a key, confirming shape + series):**
  `https://api.eia.gov/v2/petroleum/pri/spt/data/?frequency=daily&data[0]=value&facets[series][]=RBRTE&sort[0][column]=period&sort[0][direction]=desc&length=1&api_key=YOUR_KEY`
- **Series:** `RBRTE` = *Europe Brent Spot Price FOB, $/bbl* (daily). WTI is `RWTC` in the same dataset.
- **Format:** JSON (v2 API). **Auth:** free API key, register at `https://www.eia.gov/opendata/register.php` (email only).
- **Rate limits:** generous; no hard public cap documented for normal use.
- **ToS:** EIA is a **US Government agency → public domain, no copyright** (https://www.eia.gov/about/copyrights_reuse.php). "You may use and/or distribute any of our data… commercially," with acknowledgement "Source: U.S. Energy Information Administration". **Verdict: SHIP-SAFE.** (Only exception: third-party-contributed content and the EIA logo/trademark — does not touch the price series.)

### 3b. Gold — the honest answer

- **LBMA Gold Price** (the benchmark auction price) is administered by **ICE Benchmark Administration** and licensed; LBMA/IBA data is **not** freely redistributable for commercial use. LANDMINE for the *official benchmark*.
- **No US-gov public-domain gold spot feed** exists comparable to EIA's oil series (EIA covers energy, not metals; FRED's gold series are third-party/London-fixing derived).
- **Practical free path:** for a *spot* gold reference (not the LBMA benchmark), the cleanest keyless option is a metals rate via an exchange/aggregator, but all carry redistribution caveats (see §5 pattern). **Verdict for official benchmark: LANDMINE. Verdict for a caveated spot reference: CAUTION** — obtainable free but not cleanly redistributable; cite as reference, don't resell.

**Commodities verdict:** Brent (and WTI) via **EIA = SHIP-SAFE, free, public domain**. Gold has **no clean free commercial source**; the official LBMA benchmark is licensed.

## 4. Global equity indices (S&P 500, Nasdaq, Dow, FTSE, Nikkei, Hang Seng) + VIX

- **FRED** (https://api.stlouisfed.org/fred/series/observations, verified HTTP 400 "api_key not set" — endpoint valid, free key at `https://fred.stlouisfed.org/docs/api/api_key.html`, JSON) **does carry** many of these: `SP500`, `NASDAQCOM`, `DJIA`, `VIXCLS`, etc.
- **But FRED's own ToS is the landmine** (https://fred.stlouisfed.org/docs/api/terms_of_use.html): *"Data series available through the FRED API may be owned by third parties and subject to copyright restrictions… you must contact the data owner to obtain permission"* for anything beyond personal use. Copyrighted series carry the word "Copyright" in their notes.
- **Verified specific copyrights (read directly on FRED series pages):**
  - `SP500`: **"Copyright, S&P Dow Jones Indices LLC. Reproduction of S&P 500 in any form is prohibited except with the prior written permission of S&P Dow Jones Indices LLC."** → **LANDMINE.** (`DJIA` = same S&P DJI restriction.)
  - `VIXCLS`: **"Copyright, Chicago Board Options Exchange, Inc. Reprinted with permission… Data in this graph are copyrighted."** → **LANDMINE.**
  - `NASDAQCOM`: Nasdaq-owned, same pattern → treat as LANDMINE for redistribution.
  - FTSE (FTSE Russell/LSEG), Nikkei (Nikkei Inc.), Hang Seng (Hang Seng Indexes Co.) are all **privately-owned indices**; not freely redistributable, and FRED's non-US index coverage is thin anyway.
- **Verdict: LANDMINE across the board.** FRED is a convenient free *pipe*, but the *content* is third-party IP the St. Louis Fed explicitly disclaims. Using S&P 500 / Dow / VIX / Nasdaq levels in a **paid client product** requires a licence from the index owner (S&P DJI, CBOE, Nasdaq, FTSE Russell, Nikkei, HSI). For *internal research* FRED is fine; for a *customer-facing brief* it is not clean.

## 6. WorldMonitor (worldmonitor.app) — what it actually fills

Fetched live: `llms.txt` (HTTP 200, 26 KB), `openapi.json` (HTTP 200, 943 KB, 229 paths), agent-card, sandbox, and live `/ask` + `/a2a`.

**Correcting the project's prior assumptions:**
- **`/ask` (concierge) IS anonymous + quota-free** — confirmed. `GET https://api.worldmonitor.app/ask?query=...` returns HTTP 200. Agent-card states: *"The concierge itself is anonymous and quota-free; the data tools it routes to are served by the WorldMonitor [API]."* **`/a2a`** is live (JSON-RPC 2.0 over HTTP POST at `https://api.worldmonitor.app/a2a`). But **`/ask` is a router, not a data feed** — it returns pointers to the right MCP/REST tool (e.g. `get_country_macro`), **not the live index/FX/commodity values**. The actual values live behind the keyed REST/MCP endpoints below.
- **Free tier ≠ free API.** Per `https://www.worldmonitor.app/pricing.md`: the free tier is **dashboard-only, no API**. REST/MCP API access starts at **API Starter $99.99/mo** (1,000 req/day, internal-commercial), **API Business $299.99/mo** (300 req/min, customer redistribution under limited R1–R3 rights). So the "60/min quota-free" impression applies to the *agent concierge*, **not** to the structured market endpoints.
- **User-Agent policy is enforced.** A live keyless call to `/api/market/v1/get-country-stock-index?country_code=AU` returned **HTTP 403 `agent_request_blocked`** — you need a descriptive UA **and** `X-WorldMonitor-Key: wm_<40-hex>`.

**Market/macro fields it DOES expose (from OpenAPI, all under `https://api.worldmonitor.app`, keyed):**

| WM endpoint | Fills which brief gap | Upstream source (matters for ToS) |
|---|---|---|
| `/api/market/v1/get-country-stock-index?country_code=AU` | **ASX 200 level** (primary index per country) | **Yahoo Finance** (stated in OpenAPI desc) |
| `/api/market/v1/list-market-quotes?symbols=...` | S&P500/Nasdaq/Dow/FTSE/Nikkei/Hang Seng index + stock quotes | Yahoo Finance |
| `/api/market/v1/list-commodity-quotes` | Brent/gold + commodity snapshot | seeded commodity snapshot |
| `/api/market/v1/get-gold-intelligence` | **gold** price, cross-currency XAU, ratios, CFTC positioning | mixed |
| `/api/market/v1/list-crypto-quotes?ids=bitcoin` | **Bitcoin/crypto** | **CoinGecko** (stated) |
| `/api/economic/v1/get-ecb-fx-rates` | EUR-pair FX | ECB |
| `/api/economic/v1/get-bis-exchange-rates` | effective exchange rates | BIS |
| `/api/market/v1/get-fear-greed-index`, `get-cot-positioning`, `list-etf-flows` | sentiment/positioning color | mixed |

- **Verdict: CAUTION (useful convenience layer, NOT a ToS launderer).** WorldMonitor genuinely *aggregates* every gap figure (ASX 200, global indices, gold, Brent, crypto, FX) behind one keyed API — operationally attractive. **But its market data is re-served from Yahoo Finance and CoinGecko**, so it **inherits those upstream restrictions** and does not convert licensed index IP into freely-redistributable data. WorldMonitor's own redistribution rights (R1–R3 on API Business) explicitly cover *derived facts / structured events / attributed headlines up to 200 chars* — **not** raw third-party index levels ("R4 full source content is not redistributable"). It is also **AGPL-3.0** software (relevant only if you self-host, not for API consumption). Treat WM as a paid convenience aggregator for *internal* brief assembly; the S&P/CBOE/Yahoo licensing questions for a customer-facing product remain unsolved by it.

## SHIP-SAFE vs LANDMINE split

**SHIP-SAFE (free, keyless-or-free-key, clean commercial ToS — add these now):**
- **AUD/USD + AUD cross rates** → RBA **F11.1 CSV** (drop-in with your existing F1 pipeline) and/or **ECB Data Portal**.
- **Brent (and WTI) crude oil** → **EIA Open Data** (free key, public domain).
- Bonus already-available macro via the same clean pattern: **ECB FX, BIS effective rates**.

**CAUTION (obtainable + citable, but do NOT build a redistributed-feed feature on them):**
- **Bitcoin/crypto** — CoinGecko/Coinbase/Kraken keyless for a cited number; any feature that resells live quotes needs a data licence (CoinGecko paid plan is the cleanest path).
- **RBA F11.1 as a *resold* FX product** (WM/Reuters carve-out) — quoting is fine, reselling is not.
- **WorldMonitor** — fine as a **paid internal aggregator** to assemble briefs faster; not a way to escape upstream index/quote licensing.

**LANDMINE (licensed IP — no free commercial source exists; licence or omit):**
- **S&P/ASX 200 index level** — S&P DJI + ASX.
- **S&P 500, Dow Jones, Nasdaq Composite** — S&P DJI / Nasdaq (FRED carries them but explicitly disclaims redistribution).
- **VIX** — CBOE-copyrighted.
- **FTSE 100, Nikkei 225, Hang Seng** — privately-owned indices.
- **Individual ASX equities (CBA/BHP/CSL)** — already known; unchanged.
- **Official gold benchmark (LBMA Gold Price)** — ICE Benchmark Administration, licensed.

## Honest gaps — brief figures STILL not obtainable free-and-clean

For a **customer-facing** brief, these remain **not obtainable** from any free commercially-safe source and require either a data licence or a deliberate "sourced under licence" citation:

1. **S&P/ASX 200 level** — the single biggest AU gap.
2. **S&P 500 / Dow / Nasdaq levels** — licensed by S&P DJI / Nasdaq.
3. **VIX** — CBOE-licensed.
4. **FTSE 100 / Nikkei 225 / Hang Seng levels** — index owners.
5. **Individual ASX equities (CBA, BHP, CSL)** — exchange/vendor licensed.
6. **Official gold benchmark** — LBMA/ICE licensed (a caveated spot reference is obtainable but not the benchmark).

**Net:** FX and oil close cleanly and for free today. Every **equity-index level, the VIX, single stocks, and the official gold price are licensed IP** — no free pipe (FRED, Yahoo, or WorldMonitor) launders that for a paid product. Recommend: ship RBA F11.1 + ECB + EIA immediately; budget a **single index-data licence** (S&P DJI or a consolidated vendor) for the index/VIX/stock figures, or present those figures in-brief under an explicit licensed-source citation rather than via a free API.
