# Agent-Native Design — Everlin deep-research + reasoning graph

## Outcome + baseline
Outcome: more of the daily brief's ~10 macro/market figures land as sourced-and-verified (or honestly not-obtained) instead of blank, WITHOUT any licensed index level (ASX200/S&P500/VIX/gold) ever entering a client-distributed PDF. Metric: (a) figure-fill rate = obtained figures / total figure slots in the assembled MorningBrief; (b) client-clean leak count = licensed/internal-tos-risk figures that reach a client-band PDF render (must stay 0); (c) trace-reconstructability = every shipped figure has a provenance label + source. Baseline TODAY (verified in code): headless.ts retrieves 6 free/official series (RBA cash, AUD/USD, ABS CPI, ABS GDP, US Treasury, EIA Brent) and stamps 4 LICENSED_GAPS as missing=true — so fill rate ~6/10 with 4 hard gaps, 0 leaks (because nothing is retrieved for the gaps yet), and Fact carries a free-text `source` string but NO structured provenance label. The research agent's job is to raise fill on the 4 gaps via internal-tos-risk/news paths while holding leak=0; step 1 (this build) makes provenance a first-class, gated field so leak=0 is enforced by a gate rather than by the absence of a retriever.

## Ontology scope
Nouns the system reasons over (grounded in src/lib): Fact { label, value:string|number|null, unit?, source, sourceUrl?, asOf?, note? } (data-sources.ts) — the retrieval atom; null=not-obtained. Figure (schemas.ts) — a number in an output; MUST cite calcKey XOR source XOR missing:true (trust-spine, superRefine-enforced). Claim { text, source(min1), assertion } (schemas.ts) — an attributed statement. AttributedItem { headline<=200, outlet, url, retrievedAt } (news-sources.ts) — the redistributable news slice. SectionReasoning { section, facts:Claim[], interpretation } (schemas.ts) — the golden FACTS/INTERPRETATION pair; interpretation with zero facts is rejected. MorningBrief (schemas.ts) — envelope+asOf+figures+claims+sections+questionForIC+disclaimer. NEW nouns this design adds: Provenance = 'client-clean' | 'internal-tos-risk' | 'unverified' (a label COMPUTED from source/sourceUrl/label, NOT yet stored on Fact). VerificationTier = 'confirmed' | 'single-source' | 'dated-read' | 'conflict' | 'not-obtained'. Shock { date, event, sourcedClaim, magnitude } (enumerate-shocks). Throughline (string) — the connecting frame. FigureCandidate { fact, candidateSource, provenance, tier, crossVerified, trace } — what the research agent PROPOSES, never commits. Scope boundary (#9): the model never emits Figure.value; it proposes a FigureCandidate and code/human commits it into MorningBrief.figures.

## Topology decision (chosen vs simpler rejected)
- **Chosen:** Single deterministic LangGraph spine (extend the existing retrieve->assemble->validate in brief-graph.ts to retrieve->reason(enumerate-shocks->throughline->signal->localise->bound-confidence->open-ic)->classify-provenance->assemble->validate->client-clean-gate->render) with ONE optional propose-only sub-agent (ResearchOrchestrator) invoked only for LICENSED_GAP targets. All reasoning nodes hold NO tools; only ResearchOrchestrator holds retrieval tools, and it commits nothing — it returns FigureCandidates the deterministic spine gates and folds in.
- **Rejected (simpler):** Pure deterministic pipeline with no research sub-agent at all (today's headless.ts): keep the 4 licensed gaps permanently blank. Rejected because the stated GOAL is to FILL the missing figures; a design that never attempts retrieval on the gaps cannot move the fill-rate metric.
- **Why:** The reasoning steps are deterministic-or-gated-LLM and share the brief's single state object, so they are nodes in one graph, not agents — a multi-agent reasoning topology would add coordination cost with no capability gain (the brief pattern is a fixed 6-step pipeline, not an open-ended plan). The ONE place that genuinely needs agentic latitude is filling a missing figure: source discovery, retrieval, untrusted-read, and cross-verification are an open search with variable steps and tool use — that is the single ResearchOrchestrator. It is propose-only so it never crosses the trust boundary; the deterministic spine remains the sole committer. Fewest agents that work: one graph + one propose-only research agent, beating both a no-agent pipeline (can't fill gaps) and a multi-agent reasoning swarm (unjustified coordination).

## Authority tiers
- T1-autonomous: deterministic reads/classification with no side effects and no external text-as-instructions — retrieveMacroSet, classifyProvenance, crossVerify, retrieveAttributedNews. Run freely under caps.
- T2-propose-only: agent/LLM steps that PROPOSE a figure, claim, or prose but commit nothing — ResearchOrchestrator, UntrustedRead, buildNarrative. Output is always a candidate gated downstream; #9 (model never emits a committed number) holds here.
- T3-gate: pure validators that can FAIL the run — validateOutput (schema + trust-spine + lint). Default-deny (#8): a claim with no source or a figure with value+no-provenance fails closed.
- T4-irreversible: the only actions that leave the trust boundary — clientCleanGate decision + renderBriefPdf into a client-band artifact + store.put. Gated (#4); an internal-tos-risk figure needs a logged per-run override by an allowlisted owner (Ansh / Jordan Lin).

## State ownership
The MorningBrief object is the single source of truth and is owned exclusively by the deterministic LangGraph spine (BriefState in brief-graph.ts, keyed by asOfDate). Facts are owned by data-sources.ts (immutable once fetched in a run). SectionReasoning[] is owned by the reason nodes; each node owns exactly ONE section name (shocks/throughline/signal-vs-level/localise-everlin/confidence/open-ic-question plus existing australia/world-and-macro/the-one-thing) so no two nodes write the same section (validate node asserts section-name uniqueness). Provenance labels and VerificationTiers are COMPUTED, never persisted onto Fact (Fact stays the raw retrieval atom); they live on the FigureCandidate and on the assembled Figure.note/source. The ResearchOrchestrator owns NO brief state — it returns FigureCandidate[] into a staging array; the assemble node is the only writer that maps a candidate into MorningBrief.figures, and only after classify-provenance + client-clean-gate approve it. The BriefStore (pipeline/store.ts) owns persisted artifacts, idempotent by date; force=true bypasses idempotency and any verification cache.

## Thinnest slice
Build ONE seam: ProvenanceClassifier — a pure, read-only, network-free, LLM-free function classifyProvenance(fact:{source, sourceUrl, label}) => { provenance:'client-clean'|'internal-tos-risk'|'unverified', rationale }. It is the precondition every downstream gate depends on (cross-verify, client-clean-gate, assemble all key off provenance), it plugs into the existing validateOutput/headless spine without touching the byte-stable render, and it is trivially eval-able against a fixture table of (source, sourceUrl, label) -> expected label. Ship it with the first four provenance_* eval cases wired as a self-test (mirroring selftest.ts), default-deny built in (unknown/empty => 'unverified', licensed label => 'internal-tos-risk' even if source looks clean). It reads only; it commits nothing; it can fail no irreversible action — yet it converts the leak=0 invariant from 'true by absence of a retriever' into 'enforced by a classified label', which is exactly what unlocks safely turning on the research agent later.
